# Nestar Tracker Leads

Create one page site for getting leads for nestar GPS tracker, copy logo, font content and colors from netstar site "https://www.netstar.co.za/, show picture of Nestar helicopter team and ground team in action recovering stolen car in south africa. this will attract customers to request quote, packages start from R129 PM, include quote lead form to get Customer Name, Surname, Cell Number, Email (Optional) card Make and Model (Optional), form send leads to email "info@motorprime.co.za"
